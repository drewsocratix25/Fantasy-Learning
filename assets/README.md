# Little Wonders artwork

Three original environments generated for this project: a fox-and-frog garden, a blue bird’s music meadow, and a rabbit’s outdoor discovery workshop. Direction: tactile storybook miniature environments, warm light, soft rounded forms, teal/apricot/gold accents, and no embedded labels or UI.

Each environment has a 1536×1024 WebP and a 768×512 source for smaller home cards. Source artwork was generated with OpenAI image generation, then resized and compressed for delivery. The app’s abstract starburst mark is a local SVG with PNG equivalents for home-screen installation.
