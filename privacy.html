Privacy

Little Wonders is made for young children, so we keep this short and we keep the data tiny. Last updated 5 September 2026.

What we collect about your child

Nothing. The games never ask a child for a name that leaves the device, a photo, a location, or anything else. There are no ads, no advertising identifiers, no analytics scripts, and no third-party trackers on any page.

What stays on your device

Stars, unlocked friends, the chosen hero and the grown-up settings are saved in your browser's local storage on that device only. Clearing the browser's site data, or tapping Reset all progress in the grown-up corner, deletes it.

Family codes (optional)

A grown-up can create a family code on the home page so progress follows the child from one device to another. When you do, we store:

  • the grown-up's email address, so we can send the code back if it is lost;
  • the family code itself, and the dates it was created and last used;
  • the game progress that syncs: star counts, unlocked items, difficulty levels, the hero's name if one was typed, and the grown-up settings.

Anyone who knows a family code can see and change that family's game progress, so treat it like a house key. You can stop syncing on a device with Forget this code on this device, and you can ask us to delete a family entirely (see below).

Supporting the project (optional)

Payments are handled by Stripe. We never see or store card numbers. Stripe tells us the email address and the subscription status, which we attach to your family code so the supporter badge shows up. You can cancel at any time from the Manage or cancel support link on the home page.

Play counts

To know whether anyone is playing, each game sends one anonymous "played today" tick per device per day. The message contains only the game's name and the date. It has no identifier, no family code and no IP address is kept. We may publish totals ("Melody Kingdom was played 1,204 times in June").

Email

We only email the address on a family code, and only to send that code back, confirm support, or answer a question you sent us. No newsletters unless you ask for one.

Where data lives

Family data is stored with Supabase in the United States and the pages are served by GitHub Pages. Fonts load from Google Fonts, which sees the request like any web server does.

Children's privacy (COPPA)

We do not knowingly collect personal information from children under 13. Every account-like feature (family codes, payments) is designed to be operated by a parent or guardian and only ever holds the grown-up's email. If you believe a child has given us personal information, contact us and we will delete it.

Your choices and deleting data

Email the address in the footer from the address on your family code and ask us to delete the family. We will remove the family, its progress and the subscription link within 30 days, and confirm by email.

Changes

If this page changes in a way that matters, we will note it here with a new date.
